# Student Portfolio Example

A simple portfolio website made with **HTML**, **CSS**, and **JavaScript**. It does not need a framework, an account, or a paid service to run on your computer.

## Preview it

1. Download and unzip `student-portfolio-example.zip`.
2. Open the folder and double-click `index.html`. It should open in your browser.
3. If the files look like plain text, right-click `index.html` and choose a browser such as Chrome, Edge, or Firefox.

## Make it yours

Open the folder in a text editor, such as Visual Studio Code. Search `index.html` for `Your Name`, `yourusername`, `you@example.com`, and the bracketed sample hobbies. Replace each with details you are comfortable sharing publicly. Change the project titles and descriptions to match projects you actually made. In `style.css`, edit the color values near the top to change the theme.

The GitHub links are placeholders. Replace them with links to your own projects. The email button opens the visitor's email app; this example does not store or send a message through a website server.

Ask a parent or guardian before publishing personal information. A portfolio can be public to anyone on the internet.

## Publish with GitHub Pages

Create a GitHub repository, upload the three website files while keeping them together, and enable GitHub Pages in the repository's Settings. GitHub's official guide explains the current setup: https://docs.github.com/en/pages/quickstart
